
# AYKOS | Corporate Website

### Digital Marketing & Regulatory Consulting

A modern and responsive corporate website developed for AYKOS, a company focused on digital marketing solutions and pharmaceutical regulatory consulting.

🌐 **Live Website:** https://aykos-company.com.br/

## 🚀 Technologies

- HTML5
- CSS3
- JavaScript
- Git & GitHub
- GitHub Pages

## ✨ Features

- Responsive design for desktop and mobile devices
- Modern and minimalist user interface
- Corporate branding and visual identity
- SEO-focused page structure
- Services and training information
- Contact form and WhatsApp integration
- Custom domain and GitHub Pages deployment

## 💻 Running Locally

Clone the repository:

```bash
git clone https://github.com/carolina-dev20/aykos-site.git
```

Open the project folder and launch `index.html` in your browser.
